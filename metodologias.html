Introducción

Una metodología es una forma ordenada y repetible de resolver un problema o planear un producto. En el sector automotriz se usan mucho dos: el 8D, para resolver problemas (por ejemplo, cuando un cliente reclama), y el APQP, para planear el lanzamiento de productos nuevos. Para mejorar procesos con datos se usa DMAIC, y para probar ideas rápido, PDCA.

8D en una frase

Ocho disciplinas que van de formar un equipo y contener el problema a encontrar la causa raíz, corregirla de forma permanente y evitar que se repita.

APQP en una frase

Cinco fases para llevar un producto desde la definición del programa hasta la retroalimentación en producción: planear y definir, diseñar el producto, diseñar el proceso, validar y evaluar.

VerificarEl 8D tiene variantes (algunas empresas añaden una D0 de respuesta de emergencia) y el APQP tiene ediciones vigentes que debes confirmar con tu cliente o con el manual oficial.

Cómo aplicarlo: elige el método

  1. Hay un reclamo o una falla concreta. Usa 8D: contén, busca la causa raíz y previene la repetición.
  2. Vas a lanzar un producto o un cambio mayor. Usa APQP: planea riesgos, controles y validación antes de producir en serie.
  3. Quieres mejorar un proceso con datos. Usa DMAIC: define, mide, analiza, mejora y controla.
  4. Quieres probar una idea pequeña rápido. Usa PDCA: planea, haz, verifica y actúa.
Los métodos se combinan: un 8D bien hecho termina actualizando el FMEA y el plan de control del APQP.
